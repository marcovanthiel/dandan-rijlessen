# Bronmateriaal — Auto met aanhangwagen: B / code 96 / BE, 2026

Onderzocht via CBR/RDW/Rijksoverheid/rijloket, 11-7-2026. "BE" = NL-rijbewijscategorie aanhangwagen (niet landkenteken België). Feiten met bron; twijfel = TE VERIFIËREN. Grenzen = toegestane maximummassa (TMM), op kentekenbewijs.

## Kg-grenzen (hard, moeten kloppen)
| | Aanhanger | Combinatie |
|---|---|---|
| **B** | ≤ 750 kg altijd; zwaarder alleen als combinatie past | ≤ **3.500 kg** |
| **Code 96** | zwaardere aanhanger toegestaan | ≤ **4.250 kg** |
| **BE** | ≤ **3.500 kg** | tot ± **7.000 kg** (3.500 + 3.500) |

**Beslisregel:** aanhanger ≤ 750 → B genoeg. Aanhanger > 750 → kijk naar combinatie: ≤ 3.500 → B; 3.500-4.250 → **code 96**; > 4.250 (of aanhanger tot 3.500) → **BE**. Let ook op het **trekgewicht** van de auto zelf (kan lager zijn).

## Code 96 vs BE
- **Code 96**: aanvulling achter B op het rijbewijs (geen aparte categorie), combinatie ≤ 4.250 kg. Geldig zolang B geldig is.
- **BE**: aparte categorie, aanhanger ≤ 3.500 kg.

## Leeftijd & vereisten
- **18 jaar**, geldig **rijbewijs B** vereist (beide).

## Opleiding & examen
- **Geen theorie-examen** (theorie al via B).
- **Eén CBR-praktijkexamen** voor zowel code 96 als BE; de keuze BE/code 96 maak je pas bij de rijbewijsaanvraag bij de gemeente. (TE VERIFIËREN: sommige niet-officiële sites noemen een aparte code 96-toets bij de rijschool; CBR/rijloket = CBR-praktijkexamen voor beide.)
- **Praktijkexamen BE** (~55 min, rit ~35 min): 1) documenten/kentekenbewijs-vragen; 2) ogentest ~25 m; 3) controlevragen beladen/aankoppelen; 4) bijzondere verrichtingen: koppelen/ontkoppelen + achteruit manoeuvreren (geen parkeerhulp); 5) examenrit. Uitslag direct.
- Kosten 2026: **€ 143,50** (tussentijdse toets optioneel € 143,50).

## Kernonderwerpen (lesstof)
- **Rijklaar maken/controle**: banden, verlichting/remlicht auto+aanhanger, kenteken aanhanger, lading vast/verdeeld, disselslot, breakaway-kabel.
- **Aankoppelen/afkoppelen**: kogelkoppeling vergrendeld + visueel checken, stekker/elektra + verlichtingstest, breakaway-kabel, neuswiel; afkoppelen stabiel/geremd.
- **Gewichten/kentekens**: TMM auto + aanhanger optellen, toetsen aan grens (B 3.500 / 96 4.250 / BE aanhanger 3.500); trekgewicht auto.
- **Rijden met aanhanger**: langere remweg, ruimer anticiperen, bochten ruimer, zijwind/slingeren, snelheidslimieten combinatie.
- **Achteruit manoeuvreren**: aanhanger draait tegengesteld, kleine correcties, beide spiegels, rustig tempo.

## Veelgemaakte fouten + tips
1. Koppeling niet volledig vergrendeld / indicator niet gecheckt (klassieke afvaller). 2. Breakaway-/oplooprem-kabel vergeten. 3. Bochten te krap. 4. Remweg onderschatten. 5. Overcorrigeren bij achteruitrijden. 6. Kentekenbewijs-/gewichtsvragen niet kunnen beantwoorden.
