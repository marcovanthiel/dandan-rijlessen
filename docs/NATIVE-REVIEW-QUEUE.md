# Native Review Queue

Gebruik dit document voor een reviewronde door een moedertaalspreker. Alleen een
reviewer die de taal daadwerkelijk beheerst mag een item als afgerond markeren.

## Werkwijze

1. Controleer de les in de live omgeving, inclusief koppen, knoppen en oefenvragen.
2. Controleer Nederlandse rijtermen op betekenis, niet alleen op letterlijke vertaling.
3. Leg elke wijziging vast met route, oorspronkelijke tekst, voorstel en reden.
4. Laat een tweede persoon steekproefsgewijs de aangepaste termen nalopen.
5. Publiceer pas na akkoord en noteer datum en reviewer in het register hieronder.

## Prioriteit

| Taal | Scope | Status | Reviewer | Datum |
|---|---|---|---|---|
| Chinees | Volledige commerciële review | open | - | - |
| Arabisch | Lessen, vragen, interface | open | - | - |
| Hindi | Lessen, vragen, interface | open | - | - |
| Turks | Lessen, vragen, interface | open | - | - |
| Vietnamees | Lessen, vragen, interface | open | - | - |
| Pools, Oekraïens, Russisch, Spaans, Portugees | Steekproef en rijtermen | open | - | - |

## Engels

Engels is momenteel alleen een interface- en marketingtaal. Start geen native
review als "volledige lestaal" voordat alle lessen en de volledige vragenbank in
het Engels zijn geschreven en inhoudelijk gecontroleerd.
